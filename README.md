# 🏏 IPL Data Analytics Dashboard

An end-to-end **IPL Data Analytics project** developed using **Power BI, DAX, SQL, and Python** to analyze IPL matches, teams, players, venues, batting, bowling, and season-wise performance.


## 📊 Project Overview

This project converts IPL match and ball-by-ball data into an interactive **Power BI dashboard**.

The dashboard provides insights into:

* 🏆 Season Winners
* 🟠 Orange Cap Holder & Runs
* 🟣 Purple Cap / Top Wicket Taker
* 🏏 Team Performance
* 👤 Player Performance
* 📈 Runs & Wickets
* 🎯 Highest Individual Score
* ⭐ Player of the Match Awards
* 🏟️ Venue Analysis
* 📊 Average First-Innings Score
* 💥 Sixes & Half Centuries
* 🎳 Economy Rate
* 🏆 Five-Wicket Hauls
* 📅 Season-wise Match Analysis

## 📐 DAX Analysis

The project includes **30 DAX measures** for analyzing different aspects of IPL performance.

Some important measures include:

* Season Winner
* Orange Cap Holder
* Orange Cap Runs
* Orange Cap Image
* Purple Cap Total Wickets
* Highest Team Score
* Average First-Innings Score
* Batting First Win %
* Total Matches
* Total Runs
* Total Wickets
* Total Sixes
* Total Teams
* Total Venues
* Most Player of the Match Awards
* Highest Run Scorer
* Highest Individual Score
* Highest Wicket Taker
* Highest Wickets
* Economy Rate
* Best Economy Rate
* Five-Wicket Hauls
* Matches Played
* Matches Won
* Matches Lost

The DAX measures use functions such as `CALCULATE`, `FILTER`, `SUMMARIZE`, `TOPN`, `MAXX`, `MINX`, `COUNTROWS`, `DIVIDE`, `RELATED`, and `USERELATIONSHIP`.
